# Changelog

## 0.1.292 - 2026-08-15

- Apple Reminders 双向同步支持“主写入列表 + 额外接收列表”：Obsidian 新任务继续写入专用的 `Memos Plus` 列表，同时可监听 Mac 默认“提醒”等其他列表，把新的未完成提醒自动导入 Markdown 待办。
- 首次启用额外列表时只导入未完成提醒，不批量导入历史已完成事项；导入后会在同步记录中保存原始 Reminder List，标题、日期、时间、优先级、完成状态和删除继续在原列表双向更新，移除额外列表只会暂停同步，不会删除任务或重新创建到主列表。
- 多个 Reminder List 使用一次 macOS JXA 调用批量读取，避免列表数量增加时重复启动 `osascript`。设置页新增“额外接收提醒事项列表”，支持每行或逗号分隔多个列表；默认留空，避免未经选择扩大读取范围。

## 0.1.291 - 2026-08-15

- “日程与任务”顶部“今日完成”统计现在是可点击的筛选入口：点击后，右侧现有任务列表立即切换为当天完成的任务，标题同步显示“今日已完成”；再次点击或切换左侧“今天”即可返回正常任务列表。
- 今日完成统计与右侧列表统一复用任务完成日期判断，兼容带 `✅ YYYY-MM-DD` 的 Tasks 任务和只有当天日期的旧完成任务。完成列表继续保留原有取消完成、打开来源和任务设置操作，并支持搜索、优先级和项目排序筛选。
- 新增按钮激活态、悬停和键盘焦点反馈；桌面端会自动展开被折叠的任务栏，移动端会切换到任务单栏，不修改 TaskIndex、Markdown 保存或 Apple 同步逻辑。

## 0.1.290 - 2026-08-15

- 修复 Apple Reminders 同步偶发并最终持续出现 `spawn E2BIG`：JXA 程序与请求不再拼进 macOS 进程参数，统一通过固定 `osascript -l JavaScript` 参数和标准输入传递；Calendar 日程读取也共用同一受限 runner，避免超长任务、日程备注或异常 Electron 环境超过 `ARG_MAX`。
- 修复旧任务元数据 `memos-plus-task- meta` 被误当作标题并在 Apple 往返同步中重复倍增的问题。同步前会兼容解析并全量清除正常/畸形重复项，再无损收敛为一个标准 `memos-plus-task-meta`；本地任务标题、Apple 标题、TaskIndex 显示与双向同步签名统一清理内部标记，受损任务会在下一次同步自动恢复而不删除任务。
- Apple 端已被污染的 Reminder 标题会强制进行一次干净回写，随后同步记录恢复为小型签名；新增超过 1MB 的 stdin 传输、12,288 个遗留标记解析、连续往返幂等和服务级自动修复回归测试，并将残余 E2BIG/进程资源错误转换为可理解的提示。

- “发送位置”改为路径摘要与操作按钮分层显示；“当前文件 / 选择文件或标题 / 使用收件箱”使用自适应网格，在窄窗口和较大界面字号下自动换行，不再挤压长路径或越出弹窗。

## 0.1.287 - 2026-08-14

- 新增共享 `UnifiedTaskComposer`：Memos Plus 首页“作为任务”、右下角快速任务面板和“日程与任务”快速输入统一复用同一套自然语言解析、识别预览、任务字段表单和目标选择，不再分别维护预览与默认值合并代码。

- 任务写入统一经过一个完成回调：默认收件箱、当前文件、智能发送目标和首页默认发送都会更新 `TaskIndex`，并仅按任务同步目标触发既有 Apple Reminders / Calendar 同步；目标选择携带已确认的任务字段，避免再次弹出第二个任务设置页面。

## 0.1.286 - 2026-08-14

- “发送到文件”窗口底部左侧新增默认关闭的“作为任务”复选框；它与目标文件、标题和发送标签页完全独立，普通文字、链接、图片说明、摘录或其他内容均可先选择任务属性，再发送到任意 Markdown 文件和标题。
- 用户主动勾选后，文件/标题选择只进入一次现有任务设置表单，可设置日期与具体时间、提醒、优先级、项目、重复和 Apple Reminders 等同步目标；强制任务意图优先于模板/项目判断，原有标题绑定任务规则继续兼容。未勾选时普通发送路径保持不变。
- 桌面弹窗和移动端文件选择面板共用同一任务意图判断、任务渲染、Markdown 写入和 Apple 同步链路；默认发送目标同样支持显式转为任务，不建立新的任务数据或同步服务。

## 0.1.285 - 2026-08-14

- 顶部“＋ 添加任务……”复用现有无 AI 自然语言解析、Markdown 任务创建、Tasks 格式和 Apple Reminder 同步链路，确认识别结果后创建。右上角“打开完整任务管理”仍进入原“日程与任务”工作台，不修改其布局、TaskIndex 或 Apple 同步底层。

## 0.1.284 - 2026-08-14

## 0.1.282 - 2026-08-11
